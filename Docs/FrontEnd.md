## What is Front-End Programming/Development? ##

Front-End Programming and Development refer to the website pages that we see visually. It usually deals with User-Interaction (UI) and User-Experience (UX). This will include coding and markup languages such as HTML, CSS, and Javascript for functionality. 


## HTML ##

HTML (Hyper-Text Markup Language) is the core of front-end web development. This allows you to create text on a screen and create formats and containers onto the page. Each file of HTML must start with what is called a boilerplate. 

```bash
    <!DOCTYPE html> 
		<html lang="en">
			<head>
                <meta charset="utf-8">
                <meta http-equiv="X-UA-Compatible" content="IE=edge">
                <meta name="description" content="">
                <meta name="viewport" content="width=device-width, initial-scale=1">
				<title>Website Title</title>
                <style>
                    css would go here
                </style>
			</head>
			<body>
                <script>
                    javascript would go here
                </script>
			</body>
		</html>
```

When creating your website, this is what you begin with. It has all opening and closing tags for everything you may need to start a page and more.
